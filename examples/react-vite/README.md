# React + Vite example

1. Create a Vite React + TypeScript app: `npm create vite@latest my-demo -- --template react-ts`.
2. Run `cd my-demo && npm install`.
3. Install FuriIME from your repository: `npm install github:OWNER/FuriIME#v0.1.0`.
4. Replace `src/App.tsx` with [`App.tsx`](./App.tsx) from this folder.
5. Run `npm run dev` and test with a Japanese IME.

The `furi-ime/react` entry imports React, but `furi-ime` core does not.
