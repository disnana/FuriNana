# Changelog / 変更履歴

## 0.1.0 — 2026-10-20

- First public-preview source package and GitHub Release bundle.
- Dependency-free IME kana capture and conservative kanji alignment.
- Configurable output (`text`, `reading`, `tokens`, `ruby`, `source`, `confidence`).
- Hiragana/katakana rendering; edit tracking and cleanup lifecycle.
- Optional React hook, TypeScript declarations, standalone offline demo.
- Bilingual GitHub Pages demo and English/Japanese documentation.
- Node unit tests and GitHub Actions for CI, Pages, and Release assets.

This version is experimental: IME compatibility and alignment accuracy vary.
